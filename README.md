 # Análisis de Rendimiento Estudiantil 📊

Este proyecto contiene un Análisis Exploratorio de Datos (EDA) aplicado a un conjunto de datos sobre el rendimiento académico de estudiantes (`StudentsPerformance.csv`). El objetivo principal es limpiar, procesar y analizar la información para descubrir patrones y responder preguntas clave sobre cómo distintos factores impactan las calificaciones en matemáticas, lectura y escritura.

## 🎯 Objetivos del Proyecto
- Realizar una exploración y limpieza inicial de la estructura de los datos.
- Crear nuevas métricas de evaluación, incluyendo un promedio general (`average_score`) y una clasificación de rendimiento (Bajo, Medio, Alto).
- Responder preguntas analíticas mediante agrupación y estadística descriptiva.
- Generar visualizaciones efectivas para comunicar los hallazgos.

## 🛠️ Tecnologías y Librerías Utilizadas
El análisis fue desarrollado en un entorno de **Jupyter Notebook** y hace uso de las siguientes herramientas:
- **Python 3**
- **Pandas**: Para la manipulación, limpieza y agregación de datos.
- **Matplotlib & Seaborn**: Para la creación de visualizaciones estadísticas.
